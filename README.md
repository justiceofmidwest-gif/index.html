# みゃくみゃくじ Webおみくじ

12種類の「脈」から今日の運勢をひとつ授ける、1日1回限定のWebおみくじです。  
スマホ・PCのブラウザで利用できます。

---

## 公開URL

[https://justiceofmidwest-gif.github.io/](https://justiceofmidwest-gif.github.io/)

---

## 使い方

1. ブラウザで上記URLにアクセス  
2. 「くじを引く」ボタンを押す  
3. 今日の運勢が結果として表示されます（1日1回まで）

---
